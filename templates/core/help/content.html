Approving papers, events, jobs and visits

Everything members submit — discussion papers, events, job postings and visits — is held for review. It is invisible to the public until an administrator approves it. All four work exactly the same way, so once you have done one you have done them all.

← Back to the admin guides

Where each type lives

  • Discussion papers — under Publications.
  • Events — conferences, workshops, seasonal schools and podcasts.
  • Jobs
  • Visits — listed under Seminars in the admin area.

Approving one item

  1. Open the relevant list from the links above.
  2. Click the item's title to read what was submitted. Check the details are sensible and that any link works.
  3. Go back to the list and click Approve or Reject in the Review column on the right.

Approving publishes the item immediately. There is no confirmation step, and the buttons disappear once the item has been reviewed.

Approving several at once

  1. Open the list and make sure you are looking at the pending items only — use the By status → Pending filter on the right, or the links above.
  2. Tick the checkbox beside each item you want to publish.
  3. At the top of the list, choose Approve selected pending items from the Action menu and click Go.

If the confirmation says fewer items than you selected, that is expected: anything already approved or rejected is skipped silently. Filter to Pending first and the numbers will match.

Always use the Approve button, not the Status dropdown

When you open an item there is also a Status dropdown you can change by hand. It works, but it skips the review record: the site will not note who approved the item or when, and those fields cannot be filled in afterwards.

Use the Approve and Reject buttons, or the bulk action, for anything you are actually reviewing. The dropdown is useful for one thing only: putting a mistakenly reviewed item back to Pending so you can decide again properly.

Rejecting

Rejected items stay in the system but never appear publicly. The submitter is not notified — as with membership applications, the site sends no rejection email, so contact them yourself if an explanation would help. Use Admin notes on the item to record why you rejected it; those notes are internal and never shown publicly.

Approved but still not showing?

Approval is the only requirement for papers and jobs. Two types also depend on dates:

  • Events — an event whose date has passed still appears on the Events page but drops off the home page.
  • Visits — once the visit's end date has passed it moves to the Archived tab. A visit with no dates at all will not appear in either tab, so make sure a start date is filled in.

If something still looks wrong, check the Status column really does say Approved — it is easy to click Reject by mistake, since the two buttons sit side by side.
