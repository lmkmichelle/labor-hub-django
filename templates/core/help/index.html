Admin guides

These pages explain how to run Labor Hub day to day. They are visible only to site administrators — regular members cannot see this section or reach these pages.

How the site fits together

Everything is managed from the admin area, which you can also reach from the Admin link in the menu under your name. It is organised by section:

  • Accounts — User applications (people asking to join) and Users (existing members).
  • Publications — discussion papers.
  • Events — conferences, workshops, seasonal schools and podcasts.
  • Jobs — the job board.
  • Seminars — visits. The public site calls these Visits, but the admin section is still labelled Seminars. They are the same thing.

Frequently asked questions

Someone says they submitted something, but I can't find it

Check the pending queue for that section using the links above. If it is not there, check whether it was already approved or rejected: remove ?status__exact=pending from the address to see every item, then look at the Status column.

A member says they never heard back after applying

Approved applicants are emailed automatically. Rejected applicants are not — the site sends nothing when you deny an application, so you need to email them yourself if you want them to know.

I approved something but it still isn't on the site

Approval is all that controls papers and jobs. Events and visits also have to be in the future: an event whose date has passed will not appear on the home page, and a visit whose end date has passed moves to the Archived tab on the Visits page.

I made a mistake — can I undo an approval?

For papers, events, jobs and visits, yes: open the item and change Status back to Pending, then approve or reject it properly. For membership applications, no — see the membership guide for what to do instead.

Can I delete something instead of rejecting it?

You can, but rejecting is usually better: it keeps a record of what was submitted and who reviewed it. Delete only genuine spam.

Something here is wrong or missing

These guides are part of the site, so they can be corrected — let the site maintainer know and they can be updated.
